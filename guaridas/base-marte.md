# Base de Marte

La base secreta de la Legión del Mal está escondida bajo la superficie de Marte, dentro de un antiguo cráter. Desde allí, sus integrantes pueden planear sus misiones lejos de las miradas de la Tierra.

## Instalaciones

- **Centro de mando:** supervisa las operaciones y recibe información de los satélites.
- **Laboratorio:** sirve para investigar el entorno marciano y construir nuevos dispositivos.
- **Hangar:** guarda las naves utilizadas para viajar entre Marte y la Tierra.
- **Zona habitable:** ofrece alojamiento, alimentos y aire respirable para el equipo.

## Seguridad

La entrada está camuflada entre las rocas y protegida por una compuerta con acceso restringido. Sensores instalados alrededor del cráter avisan al centro de mando si alguien se acerca.

## Propósito

La base funciona como refugio y centro de operaciones. Su ubicación remota permite a la Legión preparar sus planes con discreción.
